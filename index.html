Lær pseudo elementer!

  • What they are: Pseudo-elements let you style specific parts of an HTML element without adding extra HTML elements.
  • Syntax: Pseudo-elements use a double colon (::) to distinguish them from pseudo-classes (:). - Pseudo-element: p::first-line - Pseudo-class: a:hover
  • ::before and ::after: These create additional content before or after an element's existing content. They typically require the content property.
  • Styling specific parts: Pseudo-elements can target particular parts of content: - ::first-letter — Styles the first letter. - ::first-line — Styles the first line of text. - ::selection — Styles text highlighted by the user. - ::placeholder — Styles placeholder text in input fields.
  • Practical uses: Pseudo-elements are commonly used for decorative effects, icons, custom underlines, overlays, and animations without cluttering your HTML.
Pseudo-classes describe an element's state (:hover, :focus), while pseudo-elements target a part of an element (::before, ::first-letter).
